## Networking Labs

Hands-on Cisco networking labs focused on designing, configuring, and troubleshooting network environments.

Topics covered include:

- VLANs and inter-VLAN routing
- Router-on-a-Stick (ROAS)
- Network Address Translation (NAT)
- OSPF dynamic routing
- IP addressing and subnetting
- Switching fundamentals
- Network troubleshooting
- Packet analysis using Wireshark

Future labs will expand into GNS3 and EVE-NG environments to simulate enterprise network architectures.
